# tictactoe_domain

Pure Dart package containing the **business logic** of the TicTacToe game.

No Flutter dependency — this package can be reused in any Dart project.

## Contents

- Game rules (win detection, draw)
- AI strategies (Easy, Medium, Hard/Minimax)
- Models (GameState, Player, Mark)
- Use cases (PlayMove, NextRound, AiMove)

## Tests

```bash
dart test
```
